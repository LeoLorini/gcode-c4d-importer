# G-CODE Importer for Cinema 4D

G-CODE Importer is a Python script for Cinema 4D that imports a 3D-printing G-code file and rebuilds it as organized mesh layers.

It is mainly designed for G-code exported from PrusaSlicer, with support for multi-filament colors, per-layer meshes, and reveal controls for visualization or animation.
